# DJ practice crate playlist notes

Session lesson:
- When the user says the playlist is for DJ practice, treat it as a **practice crate**, not a general listening set.
- Tighten the set by favoring steady, mix-friendly tracks over vibes alone.

Selection heuristics:
- Keep tracks with stable tempo and phrasing.
- Prefer long intros/outros, clean drum passages, and predictable transitions.
- Favor instrumental or sparse-vocal tracks for controller drills.
- Remove tracks that are too short, too busy, or better as listening-only picks.

Playlist update pattern:
- If an existing playlist has drifted, **replace/trim** it instead of only appending more tracks.
- After edits, verify final contents by reading back the Plex playlist items.
- For bulk adds/removals in Plex, use the playlist items endpoint and confirm the resulting leaf count.

This file is intentionally narrow and session-derived. The umbrella skill should stay class-level; use this reference for the exact practice-crate curation pattern.
