SKILL 01

context-repo

Resolves one private GitHub repository and its fixed local clone, then returns the clone path and a receipt.

Never claims ready or created until fresh remote and local reads agree.

SKILL 02

retro-analysis

Writes dated snapshots under retros/, and reads the store before it writes.

Shared history is what makes compare and global work across machines.

SKILL 03

shared-knowledge-artifact

The Artifact page stays authoritative. Agent-driven publishes mirror ledger.json and page.html.

The repository copy is recovery and diffable history, not the complete log.

EVERY RUN ENDS IN ONE STATE

READY

reused, nothing created

CREATED

new store, read back and verified

LOCAL_ONLY

declined, or known but unreachable

BLOCKED

gh missing, or verification disagreed

The caller always gets a definite answer, never a silent partial success.

A push that appears to succeed is not proof. CREATED is claimed only after a fresh read-back agrees.

One consented store gives every skill durable context without weakening verification.
