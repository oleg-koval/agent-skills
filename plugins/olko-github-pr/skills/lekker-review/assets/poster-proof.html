PROOF 01

Refute It

One verifier applies five adversarial challenges to one finding.

Scan: no findings verified.

Medium: Criticals verified.

Deep: Criticals and Importants verified.

PROOF 02

Keep the Rule

Teams define hard rules in references/house-rules.md.

Reviewers tag violations with rule; they stay Critical.

Runtime questions cannot prove standards and would drop non-negotiable findings.

Rule-tagged findings skip provers; policy has no failing test.

PROOF 03

Prove the Bug

At medium and deep depth, up to five non-rule Criticals get a prover.

It runs in the isolated worktree.

Captured red demonstrates the Critical bug.

Green is counter-evidence: downgrade or justify.

PROOF 04

Fix, Then Verify

One fix agent edits each file.

A read-only verifier reads the real git diff.

A red proof after the fix reverts the group.

Nothing is pushed without explicit confirmation.

PROOF 05

Keep It Living

Reviews publish a private artifact page by default.

Re-reviews update the same URL.

A timeline shows what changed since the last review.

Findings close commit by commit.

COUNTER-EVIDENCE

RED = bug demonstrated GREEN = code behaved correctly

A green proof cannot silently remain Critical. It must be downgraded or explicitly justified.

An executed test outranks an agent's opinion. If the proof stays red after a fix, the group is reverted.
